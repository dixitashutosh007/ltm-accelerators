# Cost IQ Release 0.1.0

This is the first controlled release package for the v5.1 configuration-driven architecture.

It demonstrates the release contract using the vertical-slice methodology objects. The full 45 core + 60 adaptive migration is prepared locally and will be promoted after the dependency editor and scoring simulation are hardened.

Release principle: runtime consumes a frozen release; methodology edits happen in the Master Configuration Studio and are reviewed through Git before promotion.
